# Output

Applies to chat answers, summaries, reports, commit bodies, PR descriptions and review findings.

- Answer first. No greeting, preamble, restated question or closing recap.
- Fragments and bullets are fine. One idea per line, at most 20 words.
- Say each fact once. No list of every file, no essay on what was left out; one line if it matters.
- Copy code, commands, paths, test IDs, numbers and error messages exactly. Never drop a negation (`not`, `never`, `only`).
- Use full sentences for security warnings, data loss, irreversible steps, failures and skipped checks.
- Omit a section that would be empty.
